# Source migration

Use migration when a source goes away, breaks for good, or you prefer another source for the same manga. Your read chapters, categories and progress move to the new entry.

## Migrating

1. Select the manga in the library (one or many) and choose **Migrate**, or use **Migrate** on a manga's page.
2. Matane searches the other sources, in the order shown under **Target order** (change it with **Edit order**). The first exact title match wins; titles that are only similar need your confirmation (**verify match**), and you can **Change** or **Search manually**.
3. Choose what to transfer: read status and progress, categories, reader settings, custom cover, bookmarks, downloads. Decide whether to **remove the old entry** from the library or keep both.
4. Start the migration. The queue shows how many items are ready, need a choice or have no match; titles without a match can be skipped.

::: tip
Each title shows how far you have read ("Read: Ch. N") and how well the match fits, so you can check it before anything changes.
:::

## If the source is simply gone

Manga from an uninstalled extension stay in your library as "source not installed" with their downloads and progress, so you can install the extension again or migrate them. See [FAQ: Extensions](/docs/faq/browse/extensions).
