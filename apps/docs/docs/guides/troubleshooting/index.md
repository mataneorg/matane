# Troubleshooting

Something not working? Start here.

- **[Common issues](/docs/guides/troubleshooting/common-issues)**: the problems people hit most, with the fix for each.
- **[Diagnosis](/docs/guides/troubleshooting/diagnosis)**: how to find out what is wrong, and how to write a bug report that gets fixed.

Also useful:

- [FAQ](/docs/faq/general) for questions that are not problems.
- [Network](/docs/guides/network) if no source loads.
- [Install](/docs/guides/install) for warnings on first start.

::: tip A source stopped working?
Almost always the website changed. That is fixed in the **extension**, not in the app: update the extension, or report it to the extension's repository. Matane itself does not provide sources.
:::
