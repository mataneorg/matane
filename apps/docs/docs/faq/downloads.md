# Downloads

## Where are my downloads?

By default in `Documents/Matane`, as `<Source>/<Manga>/<Chapter>`. Change it in **Settings, Downloads**; Matane offers to move what you already downloaded.

## CBZ or folder?

**CBZ** is one file per chapter with `ComicInfo.xml`, readable by other comic apps. A **folder** keeps the plain images. Set it in **Settings, Downloads, Format**.

## Why did a download fail?

Check the error on the **Downloads** page and retry. The size limit stops automatic downloads (manual ones still work), and sources' rate limits still apply.

## Does the queue survive closing the app?

Yes. With **Resume the queue on start** it continues by itself; otherwise unfinished downloads wait, paused, until you resume them.

## Can chapters delete themselves after I read them?

Yes: **Settings, Downloads, Delete after reading**, with bookmarked chapters and categories you can keep. It is off by default.

## What if a source removes a chapter I downloaded?

It stays readable and is marked "Removed from source".

## Can I read downloads in other apps?

CBZ chapters can be opened by other comic apps. See [Downloads and offline](/docs/guides/downloads).
